# 01-exit

## 이 코드가 하는 일
- 커널에 "종료 코드 0으로 프로그램 끝내줘"라고 부탁하는 최소 프로그램

## 빌드 & 실행
```bash
as --32 -g exit.s -o exit.o
ld -m elf_i386 -o exit exit.o
./exit; echo $?
```

## 실험
- 원본 `mov ebx, 0` → `0`
- `mov ebx, 42`로 변경 → `42`
  - 해석: `ebx`에 넣은 값이 그대로 종료 코드가 됨. 프로그램은 이 값을 셸에 넘기기만 하고, 화면에 찍는 건 `echo $?`
- `int 0x80` 주석 처리 → `Segmentation fault`, `139`
  - 해석:
    - 커널을 안 불렀으니 프로그램이 안 끝남
    - CPU는 코드 끝을 몰라서 `mov ebx, 42` 다음 칸(0이나 쓰레기)도 명령인 줄 알고 계속 실행
    - 그러다 접근 금지 메모리를 건드림 → Segmentation fault (segfault)
    - `139` = 128 + 11 → 11번 시그널(SIGSEGV)로 강제 종료됐다는 표시
    - 결론: 프로그램은 저절로 안 끝남. 커널한테 직접 "끝내줘"라고 부탁해야 함 → `int 0x80` 필수
